# QAZAQ RESISTANCE

GitHub Pages-ке арналған қазақ тіліндегі тарихи зерттеу платформасы.

## Іске қосу

1. Архивті ашып, ішіндегі `index.html`, `css/`, `js/`, `data/`, `config.js` файлдарын репозиторийдің негізгі деңгейіне орналастырыңыз.
2. Репозиторийде **Settings → Pages → Deploy from a branch → main → /(root)** таңдаңыз.
3. `config.js` файлында Supabase URL және publishable key конфигурацияланған. Бұл кілт браузерде көрінетін жария кілт; `service_role` кілті қолданылмайды.
4. Сауалнама сақтау үшін Supabase Dashboard → SQL Editor бөлімінде `sql/supabase.sql` скриптін бір рет орындаңыз.
5. GitHub Pages жариялаған URL-ді ашып, `docs/TEST_CHECKLIST.md` бойынша тексеріңіз.

## Негізгі бөлімдер

- 6 көтерілістің толық сипаттамасы және хронологиясы.
- Leaflet + OpenStreetMap негізіндегі аймақтық карта. Нүктелер тарихи аймақтарды шамамен көрсетеді.
- 10 тарихи тұлғаның өмірбаяны. Нақты портрет файлы берілмегендіктен, карточкалар көркем реконструкция ретінде анық белгіленген.
- 10 тезис, 30 дереккөзге сілтемесі бар тарихи факт және 3 YouTube видеосы.
- 5 сауалнама, әрқайсысында 10 сұрақ және үш жауап форматы.
- Жиынтық диаграммалар. Шағын топтағы деректі қорғау үшін бір сұрақ бойынша 5-тен аз жауап болса, нәтижелер жасырылып тұрады.

```text
index.html

data/geojson/history-regions.geojson

```

Жоба сыртқы CDN ресурстарын (Google Fonts, Leaflet, Chart.js, Supabase JS, OpenStreetMap тақталары және YouTube) және тұлғалар бөліміндегі дереккөзге сілтемесі берілген қашықтағы суреттерді қолданады, сондықтан толық жұмыс істеуі үшін интернет қажет. Сурет сервері уақытша қолжетімсіз болса, карточкада белгіленген монограмма қалады.

## Тарихи дәлдік жөнінде

Материал ғылыми және институционалдық дереккөздерге сілтенеді. Қозғалыстардың кезеңдері кей жарияланымда өзгеше берілуі мүмкін; Есет Көтібарұлының датасына қатысты ескерту сайтта көрсетілген. Қатысушы санын дәл беретін жерде ол дереккөздің өз тұжырымы ретінде белгіленеді. Карта қазіргі әкімшілік шекараларды тарихи шекара деп көрсетпейді. AI сұхбат жарияланғанда реконструкция екені белгіленуге тиіс.

## GitHub репозиторийіне салу

Осы архивтің ішіндегі файлдарды GitHub-тағы репозиторийдің root қалтасына жүктеңіз. GitHub Pages статикалық сайт ретінде іске қосылады; build command қажет емес.
